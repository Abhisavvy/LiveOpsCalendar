Batch import wizard — layout directions

Three structural patterns for guiding users through file selection, mapping, validation, and confirmation without losing context.

A
Full-width stepper — One focused step per screen with a fixed header (progress + back/skip) and a wide primary action zone. Best when each stage needs undivided attention and mobile-first clarity.
B
Split workspace — Left rail for upload, mapping, and errors; right pane for live preview table and row-level fixes. Best when users must reconcile source data against mapped columns while staying in one view.
C
Compact guided panel — Modal or slide-over with a slim vertical step list and condensed body. Best for embedding import into an existing ops screen without a full-page takeover.
